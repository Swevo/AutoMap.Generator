Add Dictionary mapping, MapNamingConvention, MapConverter, MapExternal; fix stale MIGRATION.md doc

- Dictionary<K,V>/IDictionary/IReadOnlyDictionary mapping, mirroring List/array collection support
- [MapNamingConvention] for separator/case-insensitive property matching (snake_case, kebab-case, etc.)
- [MapConverter(typeof(Converter), "Method")] for reusable static value converters
- [MapExternal(typeof(Source), typeof(Dest))] to map types you don't own, via a placeholder type
- Corrected MIGRATION.md claim that IQueryable projection is unsupported (supported since v1.12.0)
- Added 7 new generator tests; updated README/CHANGELOG docs
